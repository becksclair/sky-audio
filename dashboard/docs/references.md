# References

## External references

### Preact
- Preact getting started: Vite is the recommended way to start for Preact apps.
- Preact Signals: signals are designed to update UI efficiently and support `createModel()` and `useModel()`.
- Preact differences to React: Preact uses real DOM events, so prefer `onInput` over React-style `onChange` when not using `preact/compat`.

### Basecoat
- Basecoat introduction: simple readable classes like `btn`, `form`, and `card`.
- Basecoat button docs: variants and sizes such as `btn`, `btn-secondary`, `btn-outline`, `btn-sm`, and `btn-lg`.
- Basecoat input docs: `input`, `label`, helper text pattern, and `aria-invalid`.
- Basecoat card docs: `card` with `header`, `section`, and `footer`.
- Basecoat form docs: parent `form` class can style child form controls.
